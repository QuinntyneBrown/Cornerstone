# @quinntyne/cornerstone

FaithTech's standalone, signal-based Angular component library. Import public APIs from
`@quinntyne/cornerstone` and add `@quinntyne/cornerstone/styles/theme.scss` to the consuming application.

The optional `@quinntyne/cornerstone/styles/compat.scss` stylesheet supports incremental migration from
the audited Liturgy and Word Up markup without adding compatibility code to the default bundle.
